## 🍱 Engineering Bento Grid

<table width="100%">
<tr>
<td width="65%" valign="top">

### 🔍 PFM-CheckIt — Plataforma Pericial Inmutable
`● PRODUCTION B2B SAAS` • `⚖️ Validez Jurídica`

Solución B2B para inspecciones técnicas que sustituye la documentación tradicional vulnerable por un pipeline de evidencias matemáticamente inmutables.

- **Integridad:** Hashing criptográfico SHA-256 por cada evidencia
- **Firma Digital:** Certificados X.509 integrados con `pyHanko`
- **No Repudio:** Timestamping cualificado de Autoridad Externa (TSA RFC3161)
- **Automatización:** Compilación dinámica de reportes PDF con `ReportLab`

[**Ver Repositorio & Código →**](https://github.com/PereJSS/PFM-CheckIt)

</td>

- **Estándares eIDAS:** Alineado con requisitos de servicios de confianza europeos.

`● HIGH-CONSISTENCY ENGINE` • `PostgreSQL / ACID`

- **Testing Automatizado:** Cobertura de tests unitarios y de integración con `Django TestCase`
